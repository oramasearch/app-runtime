# app-runtime v0.1.3

**Released 2026-10-27. A patch release**, with lake v0.8.1 (lake#1260):
Streamlit page updates over 1 MiB reach the browser. Since [v0.1.2](v0.1.2.md). Image: `docker.io/oramasearch/app-runtime:v0.1.3`.

## What it includes

| PR | Change |
|---|---|
| #27 | The Streamlit proxy relays messages of any size from the App's Streamlit. A page update over 1 MiB (a large table or chart) closed the stream, so the page stopped updating and a sidebar filter seemed to do nothing (#26, agent-application#64). |
