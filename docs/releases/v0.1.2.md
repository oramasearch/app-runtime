# app-runtime v0.1.2

2026-10-26. A patch on top of [v0.1.1](v0.1.1.md). Image: `oramasearch/app-runtime:v0.1.2`.

## What it changes

- **Apps show non-ASCII text correctly** (#22): the loader takes each file's bytes from Lake's `content_base64`, which is
  exact. Lake's `contents` text form writes every non-ASCII byte as literal `\xNN` text (lake#1238), so an App's
  title showed `\xF0\x9F\x91\xA5` for 👥. `contents` is used only when no base64 form is sent.
